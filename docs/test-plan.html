8 · Please don’t report these — already known

  • A teacher can edit coverage for subjects they don’t teach. Opening any student they can see lets them tick any subject, not only their own.
  • The app is slow to load on first open. The main bundle is about 1 MB; the database is hosted, so some screens take a second or two.
  • Moments are empty in the demo data — uploading is untested here.
  • Weekly updates have to be generated by an admin before a parent sees one, so “No weekly update yet” is expected on a fresh seed.
  • Web push notifications are off. In-app notifications (the bell) are the only channel.
  • Voice recording / AI is not built yet — the class record is typed by hand by design.

9 · Reporting something

For anything that fails, please note down:

  1. The case ID (e.g. ADM-20) — or the screen, if it wasn’t in this list.
  2. Which account you were signed in as.
  3. What you expected versus what actually happened.
  4. A screenshot if the screen looked wrong.
  5. Whether it happens every time or only once.

If a whole screen fails to load, press F12, open the Console tab, reload, and screenshot anything in red — that usually says exactly what broke.
